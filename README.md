# Food Tasker (Food Delivery Application)
## About The Project
This Food Delivery Application is a multi-user platform designed to streamline the process of ordering, delivering, and managing food services for restaurants, customers, and couriers. It provides a comprehensive solution for food delivery, incorporating features like real-time order tracking, secure payment processing, and efficient delivery management. The backend, developed using Python/Django, ensures robust and secure data handling, while the mobile apps, built with Swift, offer a user-friendly interface for customers and couriers. The integration of Stripe for payments and Google Maps for location services further enhances the application's functionality, making it a complete solution for modern food delivery services.

The whole system includes:
1. **Web App for Restaurants [Python]** <br>
Web Application Dashboard for restaurants to register, create Meals and monitor Orders.
2. **Mobile App for Customers [Swift]** <br>
Customers use this app to browse, place the order and track the order's status in real-time.<br>
3. **Mobile App for Couriers [Swift]** <br>
Couriers/Drivers will use this app to pick up the orders from Restaurant and deliver food to the customers.

### Features
- User Registration and Authentication: Secure registration and login for restaurants, customers, and couriers, ensuring data protection.
- Menu Management: Restaurants can upload and manage their menus, including photo uploads and real-time updates.
- Order Placement: Customers can browse menus, place orders, and make payments securely through the integrated payment gateway.
- Real-Time Order Tracking: Both customers and couriers can track orders in real-time, with live updates on delivery status.
- Delivery Management: Couriers receive notifications for new orders, navigate to pick-up locations, and deliver food using the integrated Google Maps service.
- Super Admin Dashboard: Centralized dashboard for managing the entire platform, including user management, order monitoring, and data visualization.
- Real-Time Notifications: Instant notifications keep all users informed about order status and updates.
- Data Visualization: Generate insightful reports using bar and pie charts for better decision-making.
- Payment Processing: Secure and reliable Visa and credit card processing through Stripe integration.
